## Plan 088 UI modernization map

Plan 088 keeps Clay's host-owned UI architecture intact: cached `ResolvedUiTheme` and `TypographyRegistry` values feed host-owned chrome (projected to CSS custom properties in the Tauri/React client theme runtime); package UI remains inert catalog data; shell slots, panes, tabs, overlays, accessibility, and filesystem labels stay host-owned.
