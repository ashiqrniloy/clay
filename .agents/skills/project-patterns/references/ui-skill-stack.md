# Mandatory UI Skill Stack

- Every Clay UI planning, implementation, review, theme, typography, layout, SDUI, and accessibility task loads `clay-ui` plus `impeccable`, `full-output-enforcement`, `high-end-visual-design`, `design-taste-frontend` before source review or edits.
- Plans list all mandatory skill files under each UI task's `Approach -> Documentation Reviewed`; plan-level evidence and evidence from another task do not substitute.
- Use all four skills as complementary lenses. Resolve conflicts through the user brief, existing Clay identity, accessibility, security, authority boundaries, component/catalog compatibility, and typed theme-token ownership.
- Adapt marketing-site guidance to Clay's Operate-mode desktop application. Do not force AIDA, hero sections, a fixed brutalist palette, hardcoded fonts/colors, GSAP, or decorative motion when they conflict with task needs.
- The retired external skill-selection router is not part of Clay's workflow.
