# 15 — UI design systems (Plans 102, 103 & 104)

End-to-end activation, switching, recovery, component/surface recipe migration,
conformance testing, package security, and accessibility fallbacks for package-contributed UI design systems.

Design language (normative): [`DESIGN.md`](../DESIGN.md) — Quiet Instrument.

> **Plan 118 rewrite (2026-09-13).** `@clay/design-instrument` (Quiet
> Instrument, [`DESIGN.md`](../DESIGN.md)) is the **only** shipped design
> system; `@clay/core` is the host-consumed baseline of the same language (the
> subset the host paints before package activation), and both are the complete
> choice set the Settings panel and the command surface offer. The former
> Neobrutal and Glass packages were **removed** (plan 118 task 9) together with
> their packages, fixtures and harness states, so no step below selects,
> verifies or installs them — UI-DS-02/16/17/19/26 were rewritten for the
> shipped system, and the older dated records further down are marked
> historical where they describe the removed packages.

### Findings from this execution (recorded, not fixed here)

1. **Harness defect (fixed):** `scripts/capture-ui-review.sh` chmod'ed
   `$home/.config` without creating it, so every fixture aborted before launch
   under `set -e`; `mkdir` now creates the directory. Without this fix no
   real-build capture in this plan was possible.
2. **Harness defect (fixed):** the coding-agent review fixture relied on a
   package-contributed command being dispatchable in the same
   `init.js` generation, so it silently captured the empty-tab fallback; it now
   loads `@clay/coding-agent` explicitly. Even so the agent _pane_ is only
   reachable through the profile command, which this host cannot drive — the
   live agent-view evidence stays UNRESOLVED (module 17).
3. **Design finding (carried to the visual review):** on the landing the
   workspace route still mounts the file browser and the outline rail, and the
   rail renders a zero-document fact block (`REVISION v1`, `STATE clean`,
   `ENTRIES 0`, `WORDS 0`) for a tab with no document. Honest values, but the
   composition implies a document; the approved `start.html` draws neither
   surface. Disposition required: hide the rail (optionally the sidebar) on the
   empty tab, or re-approve the chrome.

   `cargo build --bins` alone leaves it stale and the client dies with
   `Session lost`; the working command is
