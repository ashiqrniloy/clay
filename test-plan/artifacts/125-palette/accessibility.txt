## 03 hint re-open / 04 lane hidden / 05 lane restored

* 03 (`03-palette-via-hint.ax.txt`) is byte-identical to 02 in the tree
  summary: the status-bar `palette` hint runs the same command as the titlebar
  trigger and `Ctrl+X Ctrl+O`, so the sheet keeps its geometry (`44,531
  1124x420`, `95 results`, `entry "Message" = /`).
* 04 (`04-lane-hidden-palette-gone.ax.txt`) has **0** `Agent lane`/`Commands`
  nodes; the lane hint flips back to `button "lane Ctrl X P"`, so hiding the
  lane removes the strip **and** the sheet and its veil (plan 125 defect D6).
* 05 (`05-lane-restored-palette.ax.txt`) restores `footer "Agent lane"`,
  `dialog "Commands" 44,531 1124x420`, `95 results`, and the retained draft
  `entry "Message" (/)`.

## Host ceilings (unchanged since plans 124/125; not app defects)

1. **No input synthesis.** `computer_use_linux_get_app_state` reports
   `can_send_development_input: false` (no XDG RemoteDesktop portal, no wtype,
   no xdotool, `ydotoold` socket missing), so no chord and no pointer click can
   be injected: `Ctrl+X Ctrl+O` is exercised through the status-bar `palette`
   hint, which dispatches the same `controlCenter.open` client command, and the
   keymap itself is pinned by `cargo test --test protocol
   example_config_control_center_chord` (Global `Ctrl+X Ctrl+O` for
   `controlCenter.open`, `Ctrl+X Ctrl+P` for `shell.toggleAgentLane`).
2. **No composer typing.** `entry "Message"` exposes no `EditableText` over the
   accessibility bus (`get_editable_text_iface()` → `None`; WebKitGTK keeps the
   editable interface on the web-content process), so the `/` query is seeded by
   the trigger, not typed.
3. **Palette rows are not activatable.** Rows are `list item`s whose only
   reported action is the WebKit stub `':'`; invoking it does nothing. So a
   picker row cannot be activated live, and the picker stages
   (`Configure Provider` → provider → auth method → `secret` → URL → OAuth) are
   verified in the fixture layer (`design-artifacts/tools/capture-lane-palette.mjs`,
   291 checks) and by `src/server/agent_picker.rs` tests; this is recorded as a
   ceiling, not a pass.
4. **The no-provider model trigger is inert.** `combo box "Configure a
   provider Model"` ignores `do_action` while the enabled `combo box "Coding
   Agent Agent type"` opens the lane's own client-side popover — consistent with
   the disabled-dropdown design for the no-provider state (the palette's
   `Configure Provider` row, which needs Enter, is the live entry point).

`client.log` carries only WebKitGTK's `impl_GetExtents: assertion
'ATK_IS_COMPONENT (user_data)'` CRITICALs, which appear when extents are
queried over AT-SPI (they also appear in the plan 124/125 review logs).
