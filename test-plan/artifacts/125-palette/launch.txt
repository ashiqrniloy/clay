# Plan 125 launch test — canonical example config, live Linux build

Task: "Launch-test the app with the canonical example config". Driver:
`launch-drive.sh` (this directory); captures in `screenshots/`; AX evidence in
`accessibility.txt`; numbers in `geometry-halo.txt`.

## Build / environment

* repo build of the day: `cd frontend && npm run build` then
  `cargo build --bin clay` (the dist assets are embedded at compile time), so
  the run exercises the shipped bundle, not a dev server.
* Linux, GNOME/Wayland session; window 1500x1151 after the harness activated it.
* canonical config copied unmodified from `examples/config/` (its shipped
  `setTheme("@clay/theme-gruvbox-material-dark")` is what the run shows — the
  review script that rewrites the theme was *not* used).
* isolated root `/tmp/plan125-launchtest` with `HOME`, `XDG_CONFIG_HOME`,
  `XDG_DATA_HOME`, `TMPDIR`, the socket, and the server's cwd/workspace all
  inside it; captures are window-cropped (plan 097 privacy rule).

```bash
mkdir -p "$root"/{home/.clay,config,data,tmp,workspace}
cp -r examples/config/. "$root/home/.clay/"
( cd "$root/workspace" && exec env HOME="$root/home" XDG_CONFIG_HOME="$root/config" \
    XDG_DATA_HOME="$root/data" TMPDIR="$root/tmp" target/debug/clay server "$root/review.sock" ) &
env HOME="$root/home" XDG_CONFIG_HOME="$root/config" XDG_DATA_HOME="$root/data" \
    TMPDIR="$root/tmp" target/debug/clay client "$root/review.sock" &
```

## Geometry, veil, halo, theme

`python3 launch-check.py screenshots/01-rest.png
screenshots/02-palette-titlebar.png 8,23` (full output in `geometry-halo.txt`):

* sheet `44,531 1124x420`: height cap 420 px holds; width equals the lane's
  inner width (1160 − 2×18 px form padding = 1124) and the composer field shell;
  the sheet's bottom border row (950) and the field shell's top border row (957)
  leave exactly **6 px** of lane background, as approved.
* veil: sidebar −1.7, pane −4.7, rail −5.0 luminance (working area dimmed over
  the rail's full height); lane foot strip, composer box and status bar **0.0**
  (the lane stays above the veil and interactive — D8's fix holds live).
* halo: across the sheet's top border the pixels rise `39 → 42 → 46 → 48 → 51`
  over rows 525–530 against a *veiled* background of 38–39 and a rest canvas of
  40, i.e. the glow is brighter than the un-veiled canvas at the edge; below the
  bottom border rows 951–953 are 53/50/47 over a 40 lane background, so the
  falloff is symmetric with **no offset** (a drop shadow would darken one side
  and carry a y offset); the sheet interior (29,32,33) is darker than the veiled
  canvas, so border+halo is what defines the edge. Recipe values
  (`commandCentre.default.root.rest` halo, `packages/design-instrument`) are what
  `tests/package_ui_conformance.rs` pins; this run shows they reach the pixels.
* theme: rest canvas (40,40,40) equals the canonical theme's `shellBg`.
