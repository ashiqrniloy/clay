# Plan: Phase 18.17 — Range Diagnostics and Syntax Error Highlighting

Implements `roadmap.md` Phase 18.17 and the approved range-diagnostic component of `decision-logs/2026-07-09-0352-tiered-tree-sitter-themable-syntax-vocabulary-theme-registry-and-opt-in-lsp.md`. This plan keeps `RuntimeDiagnostic` for document/session failures and adds a separate, versioned, viewport-bounded range-diagnostic path reusable by Tree-sitter, packages, and future LSP bridges.

## Objectives

- Add a first-class `DiagnosticSpan` primitive carrying byte range, severity, code, message, source, and package/core provenance without overloading document-level `RuntimeDiagnostic`.
- Produce range diagnostics generically from Tree-sitter `ERROR` and `MISSING` nodes through the existing background parse coordinator, with no language-specific Rust branches.
- Render info/warning/error diagnostics as theme-owned inline squiggles or underlines composed additively with syntax and semantic decorations.
- Expose one bounded, permissioned Clay JS publication API that future package analyzers and Phase 18.21 LSP bridges can reuse.
- Preserve viewport bounds, stale-version rejection, UTF-8 safety, payload/cache budgets, server authority, and local typing/rendering latency.

## Expected Outcome

- Invalid Rust, TypeScript, TSX, JavaScript, and Markdown syntax produces inline theme-colored diagnostics from first-party Tree-sitter grammars after asynchronous parsing.
- `DiagnosticSpan` metadata survives validated server publication, `rkyv` transport, client application, and native rendering without becoming a toast or erasing syntax/semantic styling.
- Zero-width Tree-sitter `MISSING` nodes receive a deterministic UTF-8-safe visible anchor while non-empty `ERROR` nodes retain their bounded byte range.
- Package analyzers can publish the same primitive through `clay:diagnostics.serverPublishDiagnostics`; later LSP packages need no parallel protocol or renderer path.
- Linux blocking validation passes: `cargo fmt --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings`, and `cargo test --all-targets`.
