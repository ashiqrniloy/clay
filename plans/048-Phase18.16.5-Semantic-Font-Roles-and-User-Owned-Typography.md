# Plan: Phase 18.16.5 — Semantic Font Roles and User-Owned Typography

Implements `decision-logs/2026-07-11-1418-semantic-font-roles-and-user-owned-typography.md`. Insert this phase after Phase 18.16 and before Phase 18.17 so diagnostics and full language packages build on role-aware text geometry. Existing Phase 18.16 work in `plans/047-*` and its uncommitted files is an entry-gate dependency, not cleanup scope for this plan.

## Objectives

- Add atomic user configuration for `monospace`, `proportional`, and `ui` profiles, each containing an ordered font-family fallback stack and logical-pixel base size.
- Let modes, syntax/semantic spans, and typed package UI components declare semantic font roles without selecting concrete families or sizes.
- Apply configured `FontStack` and `FontSize` values to Parley layout while preserving correct cache invalidation, wrapping, caret geometry, selection, hit testing, viewport extraction, scrolling, and fallback.
- Consolidate Clay-owned and package UI typography around the UI profile, including text-dependent layout, pointer regions, and accessibility geometry.
- Preserve server/client authority, inert package contracts, bounded protocol payloads, and no package JavaScript or IPC in paint/input/layout hot paths.

## Expected Outcome

- `~/.config/clay/init.js` can atomically call `setTypography({monospace, proportional, ui})`; valid state reaches every client at bootstrap and through live updates.
- Code defaults to monospace, prose/Markdown defaults to proportional, Markdown code spans/blocks use monospace, and Clay/package component text defaults to UI.
- Named unavailable fonts fall back through validated generic families without server-side installed-font checks or rendering failure.
- Typography and layout-affecting span revisions invalidate Parley layout and dependent UI geometry without introducing synchronous server/JavaScript work into local interaction paths.
- Linux blocking validation passes: `cargo fmt --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings`, and focused protocol/editor/package/docs tests.
