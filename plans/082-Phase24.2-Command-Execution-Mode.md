# Phase 24.2: Command Execution Mode

Prerequisite: Plan 081 (Phase 24.1 — Transient Menu Interaction Round-Trip) is complete with all 13 tasks checked. Preserve its current working-tree implementation before executing this plan.

Scope boundary: this phase makes the existing server-owned Control Center complete and user-reachable. It adds the live command catalogue, `shell.client*` activation bridge, shared fuzzy matcher, and default single-stroke binding. It does **not** add path browsing (24.3), centered/scrim rendering (24.4), or multi-stroke key routing (24.5). Until 24.5, the default is the existing single-stroke-compatible `Ctrl+Shift+P`; 24.5 may add or replace it with a sequence binding.

Decision source: `decision-logs/2026-08-11-1711-command-centre-surface-path-mode-and-sequence-keybindings.md`.

## Objectives

- Open command execution mode from a default, user-rebindable key binding.
- List every currently executable built-in, `shell.client*`, and runtime package command within existing transient-menu bounds, with current key bindings, routing policy, and exact provenance.
- Replace substring filtering with one Clay-owned bounded fuzzy subsequence matcher shared by transient-menu consumers.
- Execute server commands through the existing command-intent side-effect path and shell commands through `ShellClientCommand::from_command_id`, without granting package code client UI authority.
- Preserve Phase 24.1 server-owned session, payload, lifecycle, and no-hot-path invariants.

## Expected Outcome

- `Ctrl+Shift+P` opens the Control Center in the active tab; `init.js` can rebind or unbind it through existing `clay:keybindings` APIs.
- Command details show effective bindings, routing, and `built-in` or exact `name@version` provenance for built-ins, all `shell.client*` commands, bundled package commands, settings commands, and runtime-registered package contributions.
- Fuzzy queries rank subsequence matches with word-boundary and consecutive-match bonuses; unmatched commands disappear and ties remain deterministic.
- Enter closes the menu and executes the selected command through its existing authority path; shell commands reach the same driver handlers as their key bindings.
- Linux blocking checks pass: `cargo fmt --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings`, relevant tests, and `cargo test --all-targets`.
