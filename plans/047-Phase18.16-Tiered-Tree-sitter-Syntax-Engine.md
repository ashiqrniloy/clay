# Plan: Phase 18.16 — Tiered Tree-sitter Syntax Engine

Implements `roadmap.md` Phase 18.16 and decision `decision-logs/2026-07-09-0352-tiered-tree-sitter-themable-syntax-vocabulary-theme-registry-and-opt-in-lsp.md` component 1. This supersedes Plan 045's web-tree-sitter-only engine choice while preserving its binding non-blocking open-parse and `ParseCoordinator::finish_task` diagnostic fixes.

## Objectives

- Stand up one engine-agnostic grammar-to-`DecorationSpan` pipeline that emits Phase 18.15 vocabulary tokens and modifiers rendered through `StyleRegistry`.
- Add three syntax backends: Tier 1 native first-party `tree-sitter-*` crates, Tier 2 host-side `web-tree-sitter` WebAssembly adapter, and Tier 3 package-JS parser fallback.
- Make engine selection deterministic, provenance-recorded, and user/package-initiated: first-party defaults to Tier 1; higher-priority Tier 2 override and user forced tier are explicit.
- Fix open-time parse so text renders immediately and handler errors surface as `RuntimeDiagnostic`s.
- Ship real Rust/TypeScript/JavaScript/Markdown query/grammar artifacts or documented reproducible build steps with provenance.

## Expected Outcome

- Rust, TypeScript, JavaScript, and Markdown highlight in production via Tier 1 native tree-sitter and emit vocabulary tokens/theme modifiers.
- Tier 2 `web-tree-sitter` can override a first-party grammar or serve a package grammar through the same pipeline; Tier 3 JS parser remains available for grammar-less languages.
- Open file render is not blocked by parse completion; parse failures produce visible runtime diagnostics rather than silent hangs.
- No per-language Rust branches exist in server/client/editor hot paths; language names live in data registrations only.
- Linux validation passes: `cargo fmt --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings`, and focused syntax/parse/package/docs tests.

## Phase 18.16.5 Typography Handoff

- Phase 18.16's engine-neutral, bounded vocabulary pipeline and no-language-branches rule remain intact.
- Phase 18.16.5 is the rendering-geometry handoff: mode defaults and syntax/semantic style maps may carry validated semantic font roles after the typography protocol, layout, and cache contracts land.
