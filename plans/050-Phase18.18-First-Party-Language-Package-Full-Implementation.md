# Plan: Phase 18.18 — First-Party Language Package Full Implementation (Rust, TypeScript, JavaScript, Markdown)

Implements `roadmap.md` Phase 18.18. Expands the Phase 18.14 grammar-only first-party packages into full first-party language packages on top of the Phase 18.16 Tier 1 native engine, the Phase 18.15 vocabulary + theme registry, the Phase 18.16.5 typography contract, and the Phase 18.17 diagnostic primitive. No per-language Rust branches; all behavior rides generic primitives (behavior manifests, command declarations, completion providers, grammar contributions, SDUI components).

This plan implements the first-party package expansion component of `decision-logs/2026-07-09-0352-tiered-tree-sitter-themable-syntax-vocabulary-theme-registry-and-opt-in-lsp.md` and respects the typography boundary in `decision-logs/2026-07-11-1418-semantic-font-roles-and-user-owned-typography.md`.

## Objectives

- Ship Tier 1 native grammar + `queries/highlights.scm` + vocabulary `styleMap` (capture → `token_type` + `modifiers`) for `@clay/rust`, `@clay/typescript`, `@clay/javascript`, and `@clay/markdown`, so highlighting renders through the active theme via the Phase 18.15 `StyleRegistry`.
- Add full mode declarations only where they provide user-visible behavior: language-specific indentation parameters, electric characters, bracket/quote pairs, comment-toggle rules, autocomplete triggers, and status items — all through generic primitives (`buildCodeEditingManifest`, `serverRegisterCommand`, `serverRegisterComponentContribution`).
- Add a priority-0 base keyword/snippet completion provider per language (e.g. `rust.keywords`) so every mode has completion before Phase 18.19/18.21 richer providers.
- Move the Markdown *decoration* role onto the Tier 1 native `tree-sitter-md` engine while keeping the Markdown preview SDUI panel package-JS (decoration and preview remain separate, per decision 0352).
- Validate open-parse cost, incremental edit cost, decoration payload (`DECORATION_PAYLOAD_BUDGET_BYTES`), scroll/render latency, and memory against Phase 14 budgets; save/compare Criterion baselines.
- Add per-language smoke fixtures and documented manual `cargo run` coverage for `.rs`/`.ts`/`.tsx`/`.js`/`.jsx`/`.mjs`/`.cjs`/`.md`, and graceful fallback when a package is disabled.

## Expected Outcome

- Rust, TypeScript, JavaScript, and Markdown are full first-party language packages: themed highlighting, mode behavior, and base completion, all on generic primitives and the Tier 1 native engine.
- Markdown preview continues to work unchanged (package-JS SDUI panel) while its decoration highlighting renders through the Tier 1 engine.
- All four packages are ready for Phase 18.21 LSP enrichment without architectural change; the Tier 1 baseline remains fully functional when no LSP package is loaded.
- Linux blocking validation passes: `cargo fmt --check`, `cargo check --all-targets`, `cargo clippy --all-targets -- -D warnings`, and `cargo test --all-targets`.
